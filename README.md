## The entry

> My doctor said cut back on salt, so now I cry directly into my food.

## How it works

`main.ts` (Node 22, no dependencies, no network, no file reads) deterministically writes that single line to `/output/entry.txt`. Two runs produce byte-identical output: 68 characters of UTF-8 text, no trailing newline, well inside the 1–200 character gate.

The joke: a doctor's order to cut back on salt is obeyed in the worst possible literal way — the salt isn't gone, it's just been replaced by tears, seasoned directly over dinner.
